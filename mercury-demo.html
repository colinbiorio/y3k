liquid mercury — interactive button system

Every shape is a procedural signed distance field shaded as chrome in one WebGL2 fragment shader. Drag across a shape to slice it (it heals). Press to clump, release to pop — the button's real action fires at the pop. Tab to a button for the traveling glint.

config knobs (per button) 
{
  shape:        'plus' | 'bars' | 'broadcast' | 'bubble' | 'ring' | 'blobs'
                | 'squiggle'            // preset routed through the path pipeline
                | any custom svgPath,   // { svgPath: 'M…', strokeWidth?: n }
  size:         48,     // px the icon body spans on screen (canvas is 1.7x for pops)
  flowSpeed:    1,      // scales the silhouette breathing rate/amplitude
  viscosity:    1,      // higher = stiffer liquid (smaller breathing)
  healMs:       750,    // how long a cursor cut takes to seal (600–900)
  popIntensity: 1,      // droplet count (10–18) + velocity on click-pop
  seed:         7.31,   // unique per button — no two flow alike, nothing loops
}
